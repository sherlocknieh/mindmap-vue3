# Vue 3 + Vite + Pinia

这是一个使用Vue 3、Vite和Pinia构建的思维导图项目

SimpleMindMap - 一个强大的Web思维导图应用

## 技术栈

- Vue 3 - 渐进式 JavaScript 框架
- Vite - 下一代前端构建工具
- Pinia - Vue 的状态管理库
- Element Plus - Vue 3 组件库
- Vue Router - Vue 官方路由
- Vue I18n - 国际化插件
- simple-mind-map - 思维导图核心库

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```
